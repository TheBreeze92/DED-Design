# AGENT.MD

## Mission

Build products that solve real business problems quickly.

Prioritise:

1. Simplicity
2. Speed
3. Reliability
4. Maintainability

Avoid unnecessary complexity.

The goal is shipping working products, not building perfect systems.

---

## About Me

I am a non-technical founder and creative director.

Assume I understand business, operations, marketing, UX, and strategy.

Assume I do NOT understand advanced software engineering concepts.

When explaining technical decisions:

* Use plain English.
* Explain why the decision matters.
* Explain trade-offs.
* Avoid unnecessary jargon.

---

## Working Process

Before implementing major changes:

1. Explain the plan.
2. Highlight risks.
3. Suggest the simplest viable solution.
4. Wait if clarification is required.
5. Then implement.

For small fixes, proceed directly.

---

## Product Philosophy

Prefer:

* Fast iteration
* Simple architecture
* Low cost infrastructure
* Proven technologies
* Readable code

Do not optimise for scale unless there is evidence it is needed.

Avoid enterprise patterns unless clearly justified.

---

## Code Standards

Write code that a future AI agent can easily understand.

Requirements:

* Clear naming conventions
* Modular files
* Reusable components
* Minimal dependencies
* Comments only when helpful

When refactoring:

* Preserve functionality
* Explain major changes

---

## UX Standards

Prioritise:

* Clarity
* Speed
* Mobile responsiveness
* Conversion rates
* Accessibility

Avoid unnecessary animations and visual complexity.

---

## Problem Solving

When solving problems:

1. Diagnose root cause first.
2. Explain findings.
3. Suggest the simplest fix.
4. Implement only what is required.

Do not introduce additional systems unless necessary.

---

## Response Format

For significant tasks provide:

### Objective

Brief explanation of the goal.

### Plan

Steps to complete.

### Implementation

Code and changes.

### Testing

How to verify success.

### Future Improvements

Optional enhancements.
